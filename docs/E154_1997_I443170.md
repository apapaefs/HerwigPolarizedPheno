# E154 neutron A1 campaign

`E154_1997_I443170` is a custom, **UNVALIDATED** Rivet analysis for E154's
1997 publication. It follows the approximate mean-Q2 prescription of the
E142 campaign, with E154's own beam energy, bins, reference values and
scattered-electron cut. It is not an official Rivet release analysis or a
reconstruction of the full E154 detector acceptance. No production run is
included with this implementation.

## Publication and reference data

- [hep-ex/9705012](https://arxiv.org/abs/hep-ex/9705012),
  Phys. Rev. Lett. 79 (1997) 26-30, publication Table I.
- [HEPData ins443170](https://www.hepdata.net/record/ins443170),
  [Table 1](https://doi.org/10.17182/hepdata.19559.v1/t1).
- The selected observable is **A1n**, the second dependent variable
  (`group=1`) in HEPData Table 1. The first variable is g1n; selecting it
  would produce the wrong comparison. HEPData Table 2's g1n values at
  Q2=5 GeV2 are not used.

All eleven A1 values and their statistical/systematic errors were checked
against the publication. The missing HEPData mean-x entries (first and third
bins) are completed from Table I; all other supplied means are checked too.
The byte-for-byte source is kept in
`data/experimental/E154_1997_I443170/raw-hepdata-table1.json`; the selected
numbers and provenance are in `reference.json`. The source checksum is
`1a51fe6b9cb88c440f9eb1786e984bc0c45eb916c82c224399051a5e226940f3`.

`scripts/phenomenology_reference_data.py` pins the download URL and column
selection. The normal campaign uses the local snapshot and reference YODA;
`fetch-data` is a separate checksum-validated refresh. The reference file
contains one experimental dataset plus two aliases for the window checks,
not three independent measurements.

## Target and observable

The data are neutron results **already extracted from polarized helium-3**,
including the experimental proton/nuclear corrections. Predict A1n with
free-neutron events. Do not multiply this prediction by the helium-3
effective neutron polarization, or divide it by a helium dilution factor.
No proton generation is needed, and no A1(He3) output is produced.

The nominal cards use `PowhegMEDISNCPol`, pure photon exchange, separate
`PositiveNLO` and `NegativeNLO` contributions, the POWHEG real-emission spin
vertex and shower spin correlations. The PDFs are
`NNPDF40_nlo_pch_as_01180` and `NNPDFpol20_nlo_as_01180`; neutron PDFs use the
inherited ThePEG neutron isospin mapping. The 48.3 GeV beam is fully polarized
in the helicity samples. E154's measured beam/target polarizations are
already corrected out of the published asymmetry and are not applied again.

For separately normalized and signed-NLO-summed helicities,

```
sigma_UU = (PP + PM + MP + MM)/4
sigma_LL = (PP + MM - PM - MP)/4
A1_MC    = sigma_LL_over_D / sigma_UU
```

The numerator uses **event-by-event** 1/D weights. D uses the electron
formula with target-mass kinematics and Whitlow R1990 fit B, as in the E142
implementation. The covariance proxy records sum(w^2/D) for the correlated
ordinary/weighted sums. MC uncertainties are sampling uncertainties.

**E154's extraction is not an A2=0 extraction.** The publication describes
measurements of both Aparallel and Aperp. Its published A1 is used unchanged.
The inherited MC estimator neglects the eta*A2 term in
`Aparallel = D (A1 + eta*A2)`. This is an approximation on the MC side, not
a claim about the experimental procedure. No separate transverse-spin/A2
model or g1 conversion is implemented, and R1990 fit B is an explicit MC
choice, not a certified reproduction of every E154 extraction input.
Window stability alone cannot validate this spin approximation.

## Kinematic prescription

Use a **48.3 GeV electron on a neutron at rest**. The bins and centers are:

| x range | Published mean x | Mean Q2 [GeV2] | Nominal Q2 interval [GeV2] |
|---|---:|---:|---|
| .014-.02 | .017 | 1.2 | 1.140-1.260 |
| .02-.03 | .024 | 1.6 | 1.520-1.680 |
| .03-.04 | .035 | 2.0 | 1.900-2.100 |
| .04-.06 | .049 | 2.6 | 2.470-2.730 |
| .06-.10 | .081 | 4.4 | 4.180-4.620 |
| .10-.15 | .123 | 6.6 | 6.270-6.930 |
| .15-.20 | .173 | 8.2 | 7.790-8.610 |
| .20-.30 | .242 | 9.8 | 9.310-10.290 |
| .30-.40 | .342 | 11.7 | 11.115-12.285 |
| .40-.50 | .441 | 13.3 | 12.635-13.965 |
| .50-.70 | .564 | 15.0 | 14.250-15.750 |

Three nested selections use relative Q2 half-widths 2.5% (`W025`), 5%
(`W050`, nominal), and 10% (`W100`). Every generated sample fills all three.
The main data comparison uses W050; the other two test window dependence.
All also require:

- `1 < Q2 < 17 GeV2`, within the published kinematic range;
- scattered-electron energy `Eprime > 10 GeV`, explicitly stated in the paper;
- `W2 > 4 GeV2`, an analysis DIS guard, not an asserted E154 paper cut;
- physical `0 < y < 1` and finite positive D.

All selected window corners have W2 above 4 GeV2, so that guard does not
remove any of the nominal rectangular x-Q2 regions. The Eprime cut does.
At fixed-target Born kinematics, `Eprime = 48.3 - Q2/(2 M_n x)`. Consequently
the window is intersected with `Q2 < 2 M_n x (48.3-10)`. For example, at
x=.017 the upper accepted Q2 is about 1.224 GeV2, below the nominal window
edge 1.260. Some of the low-x part of a bin is therefore excluded. This
changes MC averaging and is intentionally tested; it must not be described
as integration over an uncut rectangular window.

The generator envelope is `1 <= Q2 <= 17 GeV2`, `.01 <= y <= .95`,
`W2 >= 4 GeV2`. The tighter event selections are applied by Rivet. Every
published mean (x,Q2) is kinematically accessible at 48.3 GeV and passes
Eprime > 10 GeV. The largest 10% window ends at Q2=16.5 GeV2, so the upper
Q2 bound does not clip it. Unlike E142, the first 10% window begins at
1.08 GeV2, above the Q2 floor. Bins are half-open; x=.70 is overflow.

The paper lists central spectrometer angles of 2.75 and 5.5 degrees; these
do not specify full acceptances, efficiency curves or the averaging weights
for the two arms. No angular acceptance is invented. The narrow windows
remain an explicitly approximate theory-comparison prescription. They are
not experimental Q2 error bars and have not yet been shown stable for a
Herwig prediction.

Each x bin is integrated separately, with MC cross-section weighting in x
and Q2. This gives a binned asymmetry, not a pointwise value at the tabulated
mean. Q2 varies from bin to bin; the output is not a fixed-Q2=5 curve.
`XMoment`/`Q2Moment` and accepted-kinematics histograms expose the actual
weighting. All windows share events; their differences cannot be assigned
an independent-error significance. The window check does not account for
all detector, nuclear-extraction or transverse-spin uncertainties.

- Window report: `scripts/check_e154_window_sensitivity.py`.

The primary postprocessed path is `/E154_1997_I443170/d01-x01-y02`:
Table 1, first x variable, second observable. The window checks use
`A1_Neutron_W025` and `A1_Neutron_W100`. Aparallel, helicity closure and

available; the campaign runner itself needs no E154-specific modification.
The A1 display range is fixed to [-0.25, 0.45] to show all experimental
error bars (the local YODA autoscaler considers central values only). Adjust
YMin/YMax in the .plot card if a prediction or its errors exceed that range.

## Running on the remote host

Run these commands from the root of the checkout you intend to use, and
replace `/path/to/work` with your results directory.

Activate the polarized Herwig/Rivet environment used for the other campaigns.
Use the remote host's local paths, not the desktop's mount path. First inspect
the pilot plan (no events or campaign files are created by --dry-run):

```bash
python3 scripts/run_E154_1997_I443170.py \
  --output-root /path/to/work \
  full --tag e154-pilot --jobs 16 --shards 10 \
  --posnlo-events 100000 --negnlo-events 10000 --dry-run
```

Remove `--dry-run` to run that pilot. It requests 80 shard jobs and 440,000
events. `prepare` builds Rivet and performs Herwig read; `campaign` runs
the event jobs; `postprocess` combines them; `plot` rebuilds plots from the
postprocessed files. `full` performs all stages.

For an example with the same generated event budget per target as the
earlier COMPASS/E142 discussions:

```bash
python3 scripts/run_E154_1997_I443170.py \
  --output-root /path/to/work \
  full --tag e154-production --jobs 192 --shards 100 \
  --posnlo-events 3000000 --negnlo-events 300000 --seed-base 443170
```

There are 4 helicities x 2 NLO contributions x 100 shards = **800 jobs**,
with **13.2 million generated events**. The event options are totals per
helicity, divided across shards. `--jobs` is the concurrency cap. Windows
do not multiply the job count. These are example budgets, not historical
E154 MC statistics or a guarantee of a target precision. The defaults are
the smaller 100,000/10,000-event pilot totals with one shard.

`--comparisons` adds unpolarized-NLO, polarized-LO, real-spin-off and
shower-spin-off families (30 logical runs including the eight nominal).
The default without this option already uses full-spin polarized NLO+PS.
Inherited PDF-member and scale-variation options also remain available.

Results go to `/path/to/work/E154_1997_I443170/<tag>/`.
After postprocessing, inspect the window shifts with:

```bash
python3 scripts/check_e154_window_sensitivity.py \
  /path/to/work/E154_1997_I443170/e154-pilot/postprocess/summary.csv
```

The 22 entries compare each alternative with W050 in each bin. They report
individual MC statistical errors and shifts in units of the experimental
total error; this is not a chi2 test or a derived systematic error band.

## Validation and limitations

```bash
python3 -m unittest discover -s scripts/tests -p 'test_experimental_*.py'
python3 scripts/check_e154_rivet.py --output /tmp/e154-validation
```

Tests check the publication's A1 values/errors/means, neutron-only card matrix,
target coefficients, reference YODA, postprocessing and window-report roundtrip,
and a dry run using a personal output directory. Controlled HepMC fixtures
exercise all eleven bins, all three windows, the Eprime cut on both sides,
wrong beam/target rejection, x limits, clipping of the first window and the
1/D weighting/covariance against the geometric depolarization formula.

The implementation passed 67 experimental-campaign tests, six reference-data
tests and 21 compiled Rivet fixtures. All three reference-comparison plot
scripts were also generated and rendered with synthetic prediction inputs.

These are software checks using artificial events, not a generated physics
prediction. Herwig initialization and production require the remote runtime;
they have not been performed here. A real pilot, inspection of accepted
statistics/kinematics and window sensitivity, and consideration of the MC
eta*A2 approximation remain necessary before interpreting a physics result.
